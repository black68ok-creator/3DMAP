# 별빛 캠핑장

밤 숲속 3D 캠핑장입니다. 같은 주소를 연 사람들끼리 실시간으로 함께 걷고, 이야기하고, 마시멜로를 구워요.

**실행:** https://black68ok-creator.github.io/3DMAP/
(Settings → Pages → Branch `main` / `(root)` 로 켜져 있어야 합니다)

## 볼거리

- 실사풍 렌더링: PBR 재질, ACES 톤매핑, 블룸, 실시간 그림자
- 셰이더로 만든 불꽃, 불티, 연기, 숯불, 흔들리는 모닥불 빛
- 절차적으로 생성한 소나무·사시나무·덤불 숲(바람에 흔들림), 바람에 흔들리는 풀과 들꽃
- 달빛이 비치는 반사 호수와 선착장, 은하수와 반짝이는 별, 반딧불
- 처짐이 있는 텐트(폴대, 스트링, 팩), 텐트 안 랜턴 불빛, 통나무 의자, 캠핑 의자, 장작 더미, 도끼 꽂힌 그루터기, 아이스박스와 랜턴, 전구 줄
- 리깅된 사람 캐릭터: 서기, 걷기, 달리기 애니메이션 블렌딩, 앉기, 손 흔들기, 끄덕, 도리도리, 점프
- **사진 한 장으로 내 캐릭터 만들기**: 사진에서 얼굴을 골라 캐릭터 얼굴에 입히고, 머리카락 색과 옷 색을 사진에서 뽑아 적용합니다. 다른 캠퍼에게도 그 얼굴로 보입니다.

## 조작

| 키 | 동작 |
| --- | --- |
| WASD / 방향키 | 걷기 (Shift 달리기) |
| 마우스 드래그 / 휠 | 시점 / 확대·축소 |
| Enter | 말하기 (머리 위 말풍선) |
| 1 ~ 8 | 이모지 반응 |
| Q · R · T | 손 흔들기 · 끄덕 · 도리도리 |
| Space | 점프 |
| E | 통나무·캠핑 의자에 앉기 |
| F | 마시멜로 꺼내기 → 불 근처에서 굽기 → 다시 F로 먹기 |
| G | 장작 넣기 (모든 사람의 모닥불이 커짐) |
| L | 손전등 |
| N · V · M · H | 낮/밤 · 1인칭 · 소리 · 도움말 |

모바일은 왼쪽 아래 조이스틱으로 움직이고, 끝까지 밀면 달립니다. 사진 버튼으로 화면을 저장하고, 그래픽 버튼으로 품질을 바꿀 수 있습니다.

## 사진 캐릭터

입장 화면의 **📷 사진 한 장으로 캐릭터 만들기** 또는 캠핑장 안의 **📷 내 캐릭터** 버튼을 누릅니다.

1. 얼굴이 잘 보이는 사진을 고릅니다 (상반신까지 나오면 옷 색도 따라옵니다).
2. 주황 동그라미를 끌어 얼굴에 맞추고 크기를 조절합니다. 점선 상자 안의 색이 옷 색이 됩니다.
3. **이 얼굴로 만들기**를 누릅니다.

사진은 브라우저 안에서만 처리되고 원본은 어디에도 올라가지 않습니다. 잘라낸 얼굴만 작은 이미지(128px, claude.ai에서는 56px)로 다른 캠퍼에게 전달되고, 이 기기에 저장돼 다음 방문 때도 유지됩니다.

## 멀티플레이

서버가 없습니다. [Trystero](https://github.com/dmotz/trystero)로 브라우저끼리 WebRTC로 직접 연결하고, 처음 서로를 찾을 때만 공개 Nostr 릴레이를 씁니다.

- 기본 방은 `campfire`입니다. 주소 끝에 `#우리방`을 붙이면 별도 방이 됩니다 (영문·숫자·하이픈).
- 🎙 음성 대화: 가까이 있는 사람일수록 크게 들립니다 (마이크 권한 필요).
- 회사망처럼 WebRTC를 막는 네트워크에서는 연결되지 않을 수 있습니다. 위치와 대화는 저장되지 않습니다.

## 개발

```bash
npm install
```

```bash
npm run build
```

```bash
npm run serve
```

- `src/main.js` 게임 루프·UI·네트워크 연결, `src/world.js` 환경, `src/fire.js` 모닥불, `src/avatar.js` 캐릭터, `src/net.js` 멀티플레이, `src/sound.js` 합성 환경음
- 빌드 결과 `app.js`를 커밋합니다 (GitHub Pages에서 바로 실행)
- 에셋 출처: `assets/CREDITS.md`
